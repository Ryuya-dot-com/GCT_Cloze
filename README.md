# GCT Context Reading Activity

Static GitHub Pages activity for practicing unknown-word inference from GCT
meaning-derivation contexts.

The activity is available from the repository root for GitHub Pages. The same
files are also mirrored in `docs/` so either Pages source setting works.

Before running the activity, set the submission address in both `config.js` and
`docs/config.js` if email submission is required.

## Classroom Use

The opening screen frames the task as unknown-word inference practice rather
than a research survey. Learners first see strategy guidance, complete several
practice items, then answer the main 20 items.

The default practice set combines four short items: broad context inference,
past-tense form (`XXXXed`), adverb form (`XXXXly`), and noun inference from a
cause-and-effect context.

## Output Workbook

At completion, the app downloads an Excel workbook with four concise sheets:

1. `Summary`: learner/session metadata, completion statistics, and run settings.
2. `Main Responses`: item-level English and Japanese response fields.
3. `Item Order`: the randomized item order shown to the learner.
4. `解答時間`: first response time, total response time, visit count, revision
   flag, start time, and completion time.

Browsers cannot attach the Excel file to an email automatically, so participants
must attach the downloaded file manually.
